# Enterprise Deployment

#concept #sales

**Enterprise deployment** refers to the requirements and patterns for deploying AI coding agents in large organizations. This is a key competitive battleground.

## Enterprise requirements

| Requirement | Description |
|---|---|
| SSO/SAML | Single sign-on integration |
| RBAC | Role-based access control |
| Audit logging | Track all agent actions for compliance |
| Data residency | Control where code and data are processed |
| Private deployment | On-premise or VPC-hosted options |
| IP protection | Ensure generated code doesn't leak proprietary info |
| Model choice | Ability to choose or restrict LLM providers |
| Admin controls | Centralized team management |
